# EXP.NO.2-IMPLEMENTATION-OF-DIGITAL-MODULATION-TECHNIQUES
## AIM
To Study and Realize ASK, FSK and PSK Modulation and Demodulation using the Digital Modulation Trainer Kit.

## APPARATUS REQUIRED
Trainer Kit, DSO(10MHz), Patch Cords and Power Supply (0-30V)

## PROCEDURE

## 1. Amplitude Shift Keying (ASK)

1. Switch on the DCL-06 kit with correct power supply polarity.
2. Select ASK modulation using Switch S1 - ASK LED will glow.
3. Observe waveforms at SINE1, SINE2, and MOD OUT.
4. Connect MOD OUT to ASK IN of ASK Demodulator.
5. Observe the demodulated waveform and note observations.

## 2. Frequency Shift Keying (FSK)

1. Switch on the DCL-06 kit with correct power supply polarity.
2. Connect SERIAL DATA (onboard) to CONTROL INPUT of Carrier Modulator.
3. Select FSK modulation using Switch S1-FSK LED will glow.
4. Observe waveforms at SINE1, SINE2, and MOD OUT.
5. Connect MOD OUT to FSK IN of FSK Demodulator.
6. Observe the demodulated waveform and note observations.

## 3. Phase Shift Keying (PSK)

1. Switch on the DCL-06 kit with correct power supply polarity.
2. Connect SERIAL DATA (onboard) to CONTROL INPUT of Modulator.
3. Select PSK modulation using Switch S1-PSK LED will glow.
4. Observe waveforms at SINE1, SINE2, and MOD OUT.
5. Connect MOD OUT to PSK IN of PSK Demodulator.
6. Observe the demodulated waveform and note observations.
